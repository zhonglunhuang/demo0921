## 1. 產品概述

- **一句話定位**：做給客戶看的 demo 網站，用於提案——把提案內容做成可以直接點、直接看的網頁，取代靜態投影片。
- **主要角色**（開票 `roles` 欄位以此為準）：
  - **客戶（提案對象）**：瀏覽 demo 網站，看得懂提案內容、能自己點過一輪。
  - **提案者**：決定 demo 要呈現什麼、調整內容與版面，並把站台部署出去給客戶看。
- **範圍邊界**：
  - **不做**：後端服務、資料庫、登入/帳號、金流、簡訊或 email 發送。
  - **模擬/暫代**：所有資料皆為前端寫死或讀靜態 JSON 的假資料；表單送出僅呈現結果畫面，不會真的送出。
  - 本站定位為提案用 demo，不是上線營運的產品。

## 3. 功能細節

> 每個功能一節：誰用、入口在哪、操作流程、規則與邊界、驗收標準。
> 對應的功能票在 frontmatter `spec:` 欄位指回本節（例：`spec: docs/SPEC.md#31-xxx`）。

> **本站的共同結構**：提案網站 = 總覽首頁 + 兩條路徑。「進系統操作」是可點可切換、有假資料在跑的模擬系統；
> 「功能導覽」是每個功能一條步驟流程，畫面逐步動起來（可自動播放 / 手動），旁邊有白話說明。
> 系統虛構品名「租務中樞」，客戶化名「安居包租代管」。假資料 103 間物件（中壢 40、內壢 25、平鎮 20、中原 18）。

### 3.1 提案站骨架

- **狀態**：✅ 已完成（票 DEMO-01）
- **誰用**：客戶自己瀏覽；提案者傳連結。
- **入口**：首頁。首屏有系統名、一句話定位、「進系統操作」「功能導覽」兩個按鈕；下方 20 個功能卡片分 7 群組。
- **進系統操作外殼**：左側導覽（手機收成抽屜）、毛玻璃頂欄、角色切換（老闆 / 租務管理員 / 會計 / 修繕人員），預設落在 AI 工作中心。
- **功能導覽播放器**：畫面區＋步驟說明＋控制列（自動播放 / 暫停、上一步、下一步、進度點），鍵盤左右鍵可用。
- **設計系統與假資料**：Apple 風（白底為主、黑底穿插、大字、毛玻璃、滾動淡入）；共用假資料含各票故事所需的數字。

### 3.2 租約與屋主

- **狀態**：✅ 已完成（票 DEMO-02）
- **#1 上游租約**：屋主、租期、付屋主租金、押金、付款日、調租、修繕責任、稅費負擔、提前解約、續租通知；物件頁上下游租約並列時間軸；上游先到期而房客仍在租 → 紅色風險警示；到期 60 天前產生續租待辦。
- **#4 押金**：每戶押金卡（收到 / 預計退還 / 扣除項目 / 退款日期與證明 / 狀態四態）；逾期未結算提醒；結算流程產生押金結算單。
- **#17 文件**：8 種文件選類型、選租客後欄位自動帶入預覽；下載 / LINE 傳送為模擬。

### 3.3 損益與儀表板

- **狀態**：✅ 已完成（票 DEMO-03）
- **#2 每房損益**：收入 − 付屋主租金 − 水電差額 − 網路 − 管理費 − 修繕 − 折舊 − 空置成本 ＝ 淨收益；年化報酬；最賺 5 間 / 快沒利潤 5 間；區域彙總句。
- **#16 老闆儀表板**：13 項 KPI、30/60/90 天到期數、6 個月現金流預估折線；可切區域。

### 3.4 空房到入住與退租整備

- **狀態**：✅ 已完成（票 DEMO-04）
- **#3 漏斗**：7 欄看板可推進；不續租自動切即將空房並產生待辦；招租頁有租金建議、刊登文案、帶看預約、訂金、簽約；平均空置天數；超過 7 天提醒價格。
- **#5 退租整備**：14 項清單可勾選附照；需修繕可建工單；全部完成才可按「可出租」回到庫存。

### 3.5 設備、修繕與資產

- **狀態**：✅ 已完成（票 DEMO-05）
- **#6 設備履歷**：每台品牌 / 型號 / 購入 / 保固 / 維修紀錄 / 累計維修費；AI 汰換建議。
- **#7 廠商與工單**：廠商分類 / 區域 / 報價 / 完工速度 / 返修率；工單報修→派工→報價→核准→完工→發票→付款；價格異常警示。
- **#8 水電異常**：12 個月趨勢＋基準線；超基準 2 倍疑似漏水、空房用電警示；一鍵建工單。
- **#9 鑰匙門禁**：各項數量與領用 / 歸還紀錄；短少自動入押金扣款；智慧鎖示意。

### 3.6 租客服務與通知

- **狀態**：✅ 已完成（票 DEMO-06）
- **#10 LINE 自助中心**：綁定房客身分；9 項選單各有回覆卡片。
- **#11 AI 客服**：依棟別 / 房間回答的腳本問答；後台知識庫依物件分組。
- **#13 證據留存**：通知紀錄（時間 / 對象 / 內容 / 送達 / 回覆）；照片依日期與房間歸檔。
- **#19 通知升級**：規則表（事件 → 層級 → 逾時升級）；案件升級時間軸。

### 3.7 事件、權限與工作中心

- **#18 待辦與績效**：每件有負責人與期限、逾期紅標；本月完成統計。
