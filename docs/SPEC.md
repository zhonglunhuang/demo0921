### 狀態圖例

| 狀態 | 意義 |
|------|------|
| ✅ 已完成 | 已實作、所有介面到位並通過驗證，可用。 |
| 🚧 進行中 | 已動工、部分完成或尚未驗收。 |
| ⏳ 未開始 | 已規劃但尚未動工。 |
| 🗑 已下線 | 曾經有、已移除。 |

> `⭐` = MVP 範圍（有 MVP 界定的專案才用，避免把後期功能誤當 MVP）。
