# 實作（general-purpose + isolation:"worktree"；預設 sonnet）

```
【目標與動機】
依票 tickets/<票號-短題.md> 實作：<需求一句話>。
背景：<誰用、解決什麼問題——從票裡抄，subagent 看不到票外討論>。

【範圍與邊界】
- 預期動的檔案：<清單或目錄>
- 明確不要動：<如「不動既有 migration」「不改 API 對外格式」>
- 遵守 AGENTS.md；使用者可見功能同步各介面與 docs/SPEC.md。

【驗收條件】
1. <可驗證條件1>
2. <條件2...>
3. `make <對應檢查>` 全綠。

【回報格式】
- 變更摘要：檔案:行號 ＋ 每檔一句話為什麼。
- 驗收自查：逐條 ✅/❌ 附證據（測試輸出關鍵行）。
- 殘留問題/假設：沒有就寫「無」。全文 ≤20 行；diff 留在 worktree 不貼。
```

實作完成 ≠ 完成：主對話仍須派 review.md 獨立驗收（dispatch.md「驗證不自驗」）。
