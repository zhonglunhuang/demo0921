- 修已失效的事實（路徑/指令改名），必附驗證證據；修錯字、斷鏈。

## 須先問使用者
- 改/刪任何規則、門檻數字、模型表；改 CLAUDE.md 路由或 hooks；新增制度檔；放寬行數上限。

- `[猜]` 標記到期（2026-10-01）仍無案例佐證 → 提議刪除（先問）；有案例 → 換成案例編號。
