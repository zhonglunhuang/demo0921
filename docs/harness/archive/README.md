## 30 秒版（記不住全部就記這個）

1. **大量讀取／掃描／批次改檔 → 派 subagent**，主對話只進結論（門檻見 10 §2）。
2. **派工必附三件套**：目標與動機、驗收條件、回報格式（模板見 30）。
3. **做完不算完成**：fresh-context 驗收＋證據才算（判準見 20 §2）。
4. **錯兩輪就升級或問人，不要第三次**（路徑見 10 §5）。
5. **對外／不可逆動作先問**（push、deploy、刪資料；判準見 20 §3）。
